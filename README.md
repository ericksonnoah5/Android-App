# Android App

> A screen-recorded demo of an Android application.

## Overview

This repository holds a video walkthrough of the app rather than its source. The
recording shows the application running on a device, stepping through its screens
and main interactions.

**Watch the demo:** https://www.youtube.com/watch?v=H7iL2TWB3JI

A local copy of the recording is also committed as `AndroidApp.mov`.

## Note on source code

The application source is not published in this repository. This repo is a demo
archive only.
